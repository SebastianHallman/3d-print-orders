# 3D printing order system with Java Spring Boot + Next.js

This project is a simple ordering system that my family can use to order 3D prints. The sole purpose of this project is to learn Java as a back end and to broaden my toolbox as a full stack developer. This is not a serious project.

## Repository structure

```/frontend``` - Next.js frontend (NOT IMPLEMENTED YET)
```/backend``` - Spring boot REST API with jdk 17

## Running the project

For the simplest approach, clone this repository and run ```docker compose up``` to run this project.

## AI usage

I used generative AI as a teacher to learn Java. All code has been written by myself, but I have used AI to ask about the code when needed.
